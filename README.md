# 🛒 PoliMarket

**PoliMarket** es una aplicación de escritorio desarrollada en C# que permite la gestión de un sistema de mercado o tienda para uso académico o comercial. Este proyecto fue realizado como parte de un trabajo universitario.

---

## 🚀 Características principales

- Inicio de sesión con validación de roles (Administrador y Empleado)
- Registro y autenticación de usuarios
- Manejo de errores con registro en archivo `.log`
- Interfaz gráfica con Windows Forms
- Arquitectura en capas (Entidad, Negocio, Presentación)
- Sistema extensible para incluir gestión de productos, clientes, ventas y más
